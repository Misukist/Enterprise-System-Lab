# Docker

<br>

## Esittely

Tässä labissa tutustuin Dockerin käyttöön ja konttiteknologiaan. Tarkoituksena oli opetella Dockerin perusteet sekä ymmärtää, miten sovelluksia voidaan suorittaa eristetyissä konteissa. Harjoittelin muun muassa Dockerin asentamista, konttien luomista ja hallintaa, imagien käyttöä sekä konttien verkottamista ja datan säilyttämistä.

Labin aikana rakensin Docker-ympäristön Ubuntu Serverille ja tutustuin myös Docker Composeen, jonka avulla useita kontteja voidaan hallita yhtenä kokonaisuutena.

Docker on hyödyllinen taito oppia, koska sen avulla sovelluksia ja palveluita voidaan suorittaa eristetyissä konteissa. Tämä helpottaa palveluiden asentamista, hallintaa ja siirtämistä eri ympäristöihin. Dockeria käytetään myös paljon työelämässä palvelinten, pilvipalveluiden ja sovellusten ylläpidossa.
