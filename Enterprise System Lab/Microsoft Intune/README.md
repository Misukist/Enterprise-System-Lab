# Microsoft Intune

<br>

## Esittely

Intune-labrassa tutustuin Microsoft Intunen käyttöön ja laitteen keskitettyyn hallintaan. Labran aikana rekisteröin Windows-laitteen Intuneen, loin erilaisia hallintapolitiikkoja ja määritin laitteen asetuksia. Lisäksi tutustuin sovellusten hallintaan sekä laitteen vaatimustenmukaisuuden (Compliance) tarkistamiseen. Labran tarkoituksena oli ymmärtää, miten Intunea käytetään organisaation laitteiden hallintaan ja tietoturvan ylläpitämiseen.
