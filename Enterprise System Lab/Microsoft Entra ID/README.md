# Microsoft Entra ID

<br>

## Esittely

Jatkoin Active Directoryn jälkeen suoraan Microsoft Entra ID käyttöön ja yllätyin siitä, kuinka paljon helpompi sitä oli hallinnoida. Myös käyttöönotto oli huomattavasti helpompaa ja nopeampaa, sillä Entra ID käyttöä varten ei tarvinnut pystyttää erillistä palvelinta. Pilvipohjaisuus teki ympäristön käyttöönotosta ja hallinnasta huomattavasti yksinkertaisempaa. opin myös tässä Labissa paljon uutta käyttäjähallinnasta.

**Osio 1: Entra ID:n käyttöönotto**  
Ensimmäisessä osiossa otettiin käyttöön Microsoft Entra ID maksuton trial-versio ja luotiin ensimmäinen tenant. Tätä tenantia käytettiin ja hallinnoitiin myöhemmissä harjoituksen osioissa.

**Osio 2: Käyttäjähallinta**  
Toisessa osiossa keskityin käyttäjähallintaan. Loin uusia käyttäjiä, toin käyttäjiä ulkopuolelta sekä määritin käyttäjille erilaisia rooleja ja käyttöoikeuksia.

**Osio 3: Ryhmien luominen**
Kolmannessa osiossa loin käyttäjä- ja Security-ryhmiä sekä lisäsin niihin käyttäjiä. Määritin ryhmille käyttöoikeuksia ja hallinnoin niille annettavia lisenssejä.

**Osio 4: Erilaisia tehtäviä**
Neljännessä osiossa loin erilaisia käytäntöjä (policy) ja tutustuin niiden testaamiseen What If -työkalulla. Lisäksi määritin monivaiheisen tunnistautumisen (MFA) asetuksia sekä tutustuin salasanojen hallintaan ja suojaamiseen.
