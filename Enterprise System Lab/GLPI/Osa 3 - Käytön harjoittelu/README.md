# Osa 3 - Käytön harjoittelu

<br>

## Esittely

Tässä osiossa harjoittelin GLPI käyttöä ja tutustuin sen eri toimintoihin. Harjoittelun tarkoituksena oli kehittää osaamistani IT-ympäristön ylläpidossa ja erityisesti tukipyyntöjen eli tikettien käsittelyssä. Harjoittelin esimerkiksi tikettien luomista, käsittelyä ja sulkemista sekä käyttäjien ja laitteiden hallintaa GLPI avulla.
